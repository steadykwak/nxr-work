# Git 커밋 메시지 생성 규칙

Source Control(source 탭)에서 커밋 메시지를 자동 생성하거나 Git 커밋 메시지를 작성할 때는 반드시 다음 규칙을 따릅니다:

1. **필수 형식**: `이모지 [요약] 설명`
2. **단일 행**: 본문, 줄바꿈, 세부 불릿 없이 **반드시 한 줄**로만 작성합니다.
3. **한국어 작성**: 영어를 사용하지 않고 **명확한 한국어**로 작성합니다.
4. **간결성과 명료성**: 장황하지 않게 핵심 변경 사항만 간결하게 기술합니다.

### 이모지 및 [요약] 기준:
- ✨ `[기능]`: 새로운 기능 추가
- 🐛 `[버그]`: 버그 및 결함 수정
- ♻️ `[리팩토링]`: 코드 구조 개선 및 모듈화
- 💄 `[스타일]`: UI/CSS 및 디자인 개선
- 📝 `[문서]`: 문서 추가 및 수정
- 🧪 `[테스트]`: 테스트 작성 및 통과
- 🔧 `[설정]`: 설정, 빌드 및 환경 구성 변경
- ⚡️ `[성능]`: 성능 향상 및 최적화
